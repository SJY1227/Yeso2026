기기 등록 (claim)
기기 등록 (claim)
카테고리
디바이스API
설명
기기가 집 와이파이 접속 후 pairingCode 로 인증. 서버가 PENDING 행을 찾아 device_uid·paired_at 를 채우고 ACTIVE 로 전환 → 응답으로 deviceAccessUuid 발급
Method
POST
URL
/device-api/v1/claim
param
body: pairingCode, deviceUid, firmware
기타
인증 헤더 없음. 핫스팩 통신은 앱→기기 단방향. pairingCode 는 일회용·유효 10분, 사용 후 비움. token · secret 은 삭제됨
사용자
기기
칸반보드
기기 동기화 및 인증 API
인증 헤더 없음. 기기가 집 와이파이에 접속한 뒤 최초 1회 호출합니다. 앱 /api/v1 과 인증 방식이 다릅니다(X-Device-Uuid).

​
token · secret 은 없어졌습니다. serverTime 은 추론 항목()으로, claim 직후 RTC 를 맞춰 첫 sync 전까지의 시각 오차를 줄이려고 넣었습니다.
서버 처리 순서: 코드로 PENDING 행을 잠그고 조회 → 만료 검증(10분) → device_uid, paired_at 채우고 ACTIVE → 서버가 device_access_uuid 생성 → pairing_code 를 비움(일회용) → 반환
