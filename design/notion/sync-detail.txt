기기 동기화 (push + pull)
기기 동기화 (push + pull)
카테고리
디바이스API
설명
완료 기록·배터리 업로드와 하루치 루틴 다운로드를 한 번에 처리. 루틴은 만들지 않고 읽기만 함
Method
POST
URL
/device-api/v1/sync
param
header: X-Device-Uuid / body: battery, firmware, completions[], dates[]
기타
응답 serverTime 으로 RTC 보정. UPDATE 기반이라 멱등성 보장. 인증은 X-Device-Uuid. 완료로 추가된 할 일 1개당 캐릭터 exp +1 (응답에는 반영 안 됨)
사용자
기기
칸반보드
기기 동기화 및 인증 API
인증: X-Device-Uuid 헤더 (claim 응답의 deviceAccessUuid). 완료 기록 · 배터리 업로드와 루틴 다운로드를 한 번에 처리합니다.
이 엔드포인트는 루틴을 만들지 않고 읽기만 합니다.
멱등: UPDATE 기반이라 네트워크 실패로 같은 completions 를 재전송해도 안전합니다. 이미 DONE 이던 할 일은 캐릭터 경험치를 다시 주지 않습니다.
응답 serverTime 으로 기기 RTC 를 보정합니다.
