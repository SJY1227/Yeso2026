1.  UX  핵심  개념  
본  디바이스는  보호자가  설정한  하루  루틴을  사용자가  따라갈  수  있도록  돕는  키링형  루틴  
보조
 
디바이스이다
.
 
루틴은
 
큰
 
루틴
과
 
작은
 
루틴
으로
 
나뉜다
.
 
큰  루틴은  사용자가  달성해야  하는  최종  목적이며 ,  작은  루틴은  그  목적을  달성하기  위한  
세부
 
행동이다
.
 
예를  들어  큰  루틴이  약국  가기라면 ,  작은  루틴은  지갑  챙기기,  버스  타기,  정류장  가기,  약국  도착하기처럼  구성된다 .  
디바이스는  보호자가  설정한  시간에  큰  루틴을  편지  형태로  알려주고 ,  사용자는  편지  
안에서
 
작은
 
루틴을
 
하나씩
 
완료해
 
나간다
.
 
작은
 
루틴을
 
완료할
 
때마다
 
랜덤
 
먹이를
 
얻고
,
 
먹이를
 
캐릭터에게
 
주면
 
성장
 
게이지가
 
오른다
.
 
즉 ,  본  UX 는  보호자가  설정한  큰  목표를  사용자가  작은  행동으로  나누어  수행하고 ,  그  
과정을
 
캐릭터
 
성장

구조
이다

2.  루틴  구조  
2.1  큰  루틴  
큰  루틴은  특정  행위의  최종  목적지를  의미한다 .  
예시 :  
약국  가기  
병원  가기  
학교  가기  
치료센터  가기  
집에  돌아오기  
마트  다녀오기  
약속  장소  가기  
 
큰  루틴은  보호자가  시간  제한을  설정할  수  있다 .  
예시 :  
큰  루틴 :  약국  가기  
시간  제한 :  10:00  ~  12:00  
 
이  시간  안에  큰  루틴이  완료되지  않으면  해당  큰  루틴은  포기  상태로  전환된다 .  
 
2.2  작은  루틴  
작은  루틴은  큰  루틴을  수행하기  위한  세부  행동이다 .  
예시 :  
큰  루틴 :  약국  가기  
 
작은  루틴

5.  약국  앞에서  내리기

2.3  큰  루틴과  작은  루틴의  관계  
큰  루틴  =  최종  목적  
작은  루틴  =  최종  목적을  달성하기  위한  세부  행동  
예시 :  
큰  루틴 :  치료센터  가기

2.  신발  신기  
3.  엘리베이터  타기  
4.  보호자  차량  타기  
5.  치료센터  도착하기  
6.  선생님  만나기  
 
사용자가  큰  루틴을  포기하면  그  안에  포함된  작은  루틴  전체가  사라지고 ,  다음  큰  루틴으로  
이동한다
.

5.  화면  꺼짐  UX  
디바이스는  배터리  절약을  위해  10 초  동안  아무  버튼도  누르지  않으면  화면이  꺼진다 .

→  10 초  동안  입력  없음  
→  화면  꺼짐  
 
화면이  꺼진  상태에서  사용자가  아무  버튼이나  누르면  다시  메인  화면으로  돌아온다 .  
화면  꺼짐  
→  아무  버튼  누름  
→  메인  화면  표시  
 
이때  편지가  도착해  있는  상태라면 ,  메인  화면에서  캐릭터  말풍선에  편지  이미지가  
표시된다
.
 
 
6.  큰  루틴  알림  UX

큰  루틴  시작  시간  도달  
→  진동  알림  
→  메인  화면에  편지  표시  
 
큰  루틴이  시작될  때마다  진동을  제공한다 .  
예시 :  
10:00  약국  가기  시작  
→  진동  
→  편지  도착

7.  편지  화면  UX  
편지  화면은  사용자가  현재  수행해야  하는  큰  루틴과  작은  루틴을  확인하는  화면이다 .  
편지  화면에는  다음  정보가  표시된다 .  
1.  상단  작은  글씨 :  큰  루틴  이름  
2.  가운데  큰  글씨 :  현재  작은  루틴  
3.  맨  위  오른쪽 :  큰  루틴  내  작은  루틴  진행률  
4.  상단  또는  하단 :  현재  큰  루틴  전체  진행률  
5.  하단  선택지 :  포기  /  완료  
 
화면  예시 :  
┌────────────────┐  
│  약국  가기   2/6  │  
│  전체  1/4        │  
│                 │  
│   7 번  버스       │  
│   타기           │  
│                 │  
│   포기     완료   │  
└────────────────┘  
 
여기서  2/6은  현재  큰  루틴  안에서  작은  루틴  6 개  중  2 번째를  수행  중이라는  의미이다 .  전체  1/4는  하루  전체  큰  루틴  4 개  중  1 번째  큰  루틴을  수행  중이라는  의미이다 .

9.  작은  루틴  완료  UX  
사용자가  작은  루틴을  수행한  뒤  완료에  커서를  두고  확인  버튼을  누르면  작은  루틴이  
완료된다
.
 
현재  작은  루틴  수행  
→  완료  선택  
→  확인  버튼  
→  작은  루틴  완료  
 
작은  루틴  완료  후에는  다음  작은  루틴으로  이동한다 .  
작은  루틴  완료  
→  랜덤  먹이  제공  
→  먹이  주기  
→  게이지  상승  
→  다음  작은  루틴  표시  
 
작은  루틴에는  시간  제한이  없으므로  사용자는  자신의  속도에  맞게  수행할  수  있다 .

11.  큰  루틴  시간  제한  UX  
큰  루틴은  보호자가  설정한  시간  제한을  가진다 .  
예시 :  
큰  루틴 :  약국  가기  
제한  시간 :  10:00  ~  12:00  
 
작은  루틴은  시간  제한이  없지만 ,  큰  루틴  전체는  보호자가  설정한  시간  안에  끝나야  한다 .  
큰  루틴의  제한  시간이  지나면  해당  큰  루틴은  자동으로  포기  처리된다 .  
큰  루틴  제한  시간  초과  
→  큰  루틴  자동  포기  전환  
→  캐릭터  슬픈  표정  
→  다음  큰  루틴으로  이동  
 
이  UX 는  보호자가  실제  수행  시간과  이동  시간을  감안해  넉넉하게  큰  루틴  시간을  
설정한다는
 
가정을
 
기반으로
 
한다

15.  새  캐릭터  제공  UX  
최종  진화가  완료되면  새로운  캐릭터가  실루엣으로  제공된다 .  
화면  예시 :  
┌────────────────┐  
│                 │  
│  새  친구  발견 !   │

│       ???        │  
│     실루엣       │  

PAGE 16
└────────────────┘  
 
사용자가  확인  버튼을  누르면  해당  캐릭터가  도감에  추가된다 .  
새  캐릭터  실루엣  제공  
→  확인  버튼  
→  도감에  추가  
 
새  캐릭터를  선택하면  1 단계부터  다시  성장  루프가  시작된다 .

→  진화  반복  
 
 
16.  도감  UX  
16.1  도감  진입  
메인  화면에서  오른쪽  버튼을  길게  누르면  도감  화면으로  들어간다 .  
오른쪽  버튼  길게  누르기  
→  도감  화면  
 
 
16.2  도감  탐색  
도감  화면에서는  앞 / 뒤  버튼으로  캐릭터를  확인할  수  있다 .  
앞  버튼  
→  이전  캐릭터  

PAGE 17
 
뒤  버튼  
→  다음  캐릭터  
 
 
16.3  캐릭터  선택  
도감  화면에서  확인  버튼을  누르면  해당  캐릭터를  선택한다 .  
화면  예시 :

└────────────────┘

┌────────────────┐  
│  도감  4/5        │  
│                 │  
│      ???         │  
│     실루엣       │  
│                 │  
│  아직  없음       │  
└────────────────┘

16.4  다른  캐릭터  선택  
이미  도감에  있는  다른  캐릭터를  선택하면  해당  캐릭터에  저장된  단계부터  게이지가  다시  
시작된다
.
 
다른  캐릭터  선택  
→  저장된  단계  불러오기  
→  해당  단계부터  게이지  시작  
 
새  캐릭터를  선택하면  처음부터  반복한다 .  
새  캐릭터  선택  
→  1 단계부터  시작  
→  성장  루프  반복  
 
 
17.  하루  요약  UX  
하루의  모든  큰  루틴이  끝나면  하루  요약  화면을  표시한다 .  
요약  기준은  큰  루틴  개수가  아니라  전체  작은  루틴  개수 이다 .  
예시 :  
오늘은  
24 개  중  20 개  성공 !  
 
또는  
오늘도  수고했어  
20/24  성공  
 
화면  예시 :  
┌────────────────┐  
│                 │  
│  오늘도  수고했어 │  

PAGE 19
│                 │  
│  20/24  성공      │  
│                 │  
│      (·ᴗ·)       │  
└────────────────┘  
 
이  요약  화면은  사용자가  집에  들어온  이후부터  밤  12 시까지  유지된다 .  
모든  큰  루틴  종료  
→  하루  요약  화면  표시  
→  밤  12 시까지  유지  
→  밤  12 시  이후  다음  날로  초기화
